Polymorphism is another essential OOP concept that allows objects of different classes to be treated as objects of a common base class. It enables us to write code that can work with objects without knowing their exact types. Polumorphism is achived through `method overriding` and `method overloading`. "**Method overriding is the practice of defining a method in a subclass that already exists in the parent class. Method overloading, on the other hand, is the ability to define multiple methods in the same class with the same name but `different parameters`**".
